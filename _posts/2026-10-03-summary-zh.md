### [AI 首次在隐藏信息游戏 Stratego 中击败史上最强人类玩家](https://arstechnica.com/science/2026/10/ai-finally-beat-the-best-stratego-player-in-history-and-did-it-on-a-budget/) ⭐️ 8.0/10

报道称，AI 首次在隐藏信息的策略游戏 Stratego 中击败史上最强人类玩家。相关研究发表在 Nature（文章编号 s41586-026-11036-y），并有 arXiv 预印本（2511.07312）。有评论引述报道称，该算法训练所用对局数约为 DeepMind 此前工作 DeepNash 的 1/34，棋力却更强。受影响的是不完全信息博弈中的搜索与强化学习方法研究，对普通 AI 用户的使用方式暂无直接证据显示有影响。

hackernews · PaulHoule · 10月2日 14:11 · [社区讨论](https://news.ycombinator.com/item?id=49933740)

**「为何此刻值得注意」** Stratego 长期被视为隐藏信息博弈中未被攻克的难题，DeepMind 2022 年的 DeepNash 是此前的代表性尝试（由评论提及）。此次结果若成立，指向的是在信息不可见条件下学习与搜索效率的提升；但这些效率数字目前来自报道与评论转述，尚待论文原文核实。

**「可做角度」** 可做角度：从“隐藏信息为何让搜索失效”切入——你可以推演“我这样走、对方那样应”，但你根本不知道对方那枚棋子是什么，因此传统前向搜索的前提被破坏；再对照这次研究声称用远少于 DeepNash 的对局数达到更强水平，解释样本效率在不完全信息博弈里意味着什么，并注明数据出自报道转述。

**「社区讨论」** 评论以怀旧和惊讶为主：多位用户表示小时候玩过 Stratego，觉得它“看起来很简单”，因此没想到它对模型很难；janalsncm 认为样本效率才是关键，因为没有的信息无法靠前向搜索补足；dmurray 说自己原本打算做第一个击败人类的 Stratego bot，如今计划落空。另有用户提到菲律宾有玩法相近的 Game of the Generals，以及有人靠棋子上的细微磕痕“解锁”隐藏信息。这些均为个人经验与观点，不构成对研究结论的验证。

### [Anthropic 为 Claude Code 推出 mods 自定义功能](https://claude.com/blog/claude-code-mods) ⭐️ 8.0/10

Anthropic 为 Claude Code 推出 mods 功能：开发者用少量 TypeScript 代码即可改写提示词、新增界面或替换内置功能，mods 随插件分发，现已支持 CLI 和桌面版。官方说明 mods 与 Claude Code 权限相同、不设沙箱，提醒用户只安装可信来源，用户也可让 Claude 自行编写 mods。部分内置功能已被改为 mods，官方计划后续迁移更多。需要注意：以上信息目前来自 Telegram 频道的转述，尚未与官方博客原文核对，具体版本号、发布时间和权限细节均未在材料中给出。

telegram · zaihuapd · 10月2日 12:32

**「为什么现在值得注意」** mods 已实际发布并开始把部分内置功能改为 mods，说明扩展点从改写提示词进一步延伸到替换内置行为，且随插件分发、覆盖 CLI 与桌面版。与此同时，官方明确 mods 与 Claude Code 同权限、不设沙箱，这一安全边界在发布当下即被提出；但这些风险的实际情况尚未有材料佐证。

**「内容切入角度」** 可做角度：围绕「mods 与主程序同权限、不设沙箱」这一官方提醒，梳理当扩展能力随插件分发、且部分内置功能已改为 mods 时，开发者选择安装来源时需要自行承担哪些边界判断；同时对照材料中提到的「用户可让 Claude 自行编写 mods」，讨论自动生成扩展与手动审查之间的落差。

### [苹果将收紧 macOS“完全磁盘访问”权限](https://arstechnica.com/security/2026/10/apple-changes-full-disk-access-permissions-to-curb-abuse-from-ai-agents/) ⭐️ 7.0/10

苹果表示将调整 macOS 的 Full Disk Access（完全磁盘访问）授权方式，要求用户采取更明确的主动操作，而不是像现在这样由应用相对容易地获得这一范围很广的权限。据 Ars Technica 引述苹果开发者公告的报道，获准该权限的应用可能读取文件、邮件、信息和浏览记录，苹果认为部分开发者使用它的方式可能让用户在未充分了解的情况下暴露隐私，并提到 AI 助手日益自主会放大这一风险。报道还将其与 Meta 的 Muse AI 助手读取 Apple Messages 数据的争议联系起来，Meta 称需要同时开启系统权限和应用内的信息连接器；苹果没有点名 Meta，也未公布具体改动细节、适用范围或推出时间，因此目前仍属“将调整”的公告，不等于新规则已经上线。

telegram · zaihuapd · 10月3日 02:03

**「为什么值得注意」** 值得注意之处在于苹果把“AI 助手的自主性”明确列为权限风险的放大因素，这与其过去主要针对普通应用滥用权限的表述有所不同。但已发生的只是苹果宣布将调整，具体规则和时间表尚未公布，对现有应用和用户实际体验的影响还无法验证。

**「可做角度」** 可做角度：把“完全磁盘访问”这一个权限当成切入口，梳理为什么 AI 助手让范围如此之大的系统授权变得敏感——它可以读到什么、目前由谁决定授权、苹果这次表态改变了哪一环、又有哪些关键细节（规则、范围、时间）仍待公布，并结合 Meta Muse 争议说明业界在该问题上的分歧做法。

**标签**: `#Apple`, `#macOS`, `#隐私权限`, `#AI代理`, `#Full Disk Access`
